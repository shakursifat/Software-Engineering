## 📌 About

This repository contains my work for **CSE 214 — Software Engineering Sessional** at the **Bangladesh University of Engineering and Technology (BUET)**.

The course is based on CSE 213 (Software Engineering) and focuses on applying software engineering concepts through practical assignments, design patterns, version control, coding practices, refactoring, and software testing.

---

## 🎯 Course Objectives

The major objectives of this course are to:

* Design software using **requirement analysis and design techniques**
* Apply **software design patterns** to appropriate scenarios
* Apply **software testing techniques and tools**

---
